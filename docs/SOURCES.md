## 참조하지 않은 자료

- 제3자 공개 HWPX 스킬(GitHub Canine89/hwpxskill 등)의 코드, 템플릿 XML, 스크립트 구성. 해당 저장소는 라이선스가 명시되어 있지 않아 참조·재사용 대상에서 제외했다.
- 설계 단계 대화에서 위 저장소의 README와 SKILL.md 앞부분을 라이선스 확인 목적으로 열람한 사실이 있으며, 구현 시에는 해당 파일을 다시 열지 않았다.

## 독자 설계 요소

- 위치 지정 체계: 논리 셀 좌표 경로(`s0/tbl[i]/r[j]/c[k]`), 라벨 기준 상대 위치(`label:성명>down#2`), 누름틀, 자리표시자
- 보존 저장 방식: 미수정 항목 원본 바이트 유지, 수정 XML만 재직렬화하며 선언부·후행 바이트·CR 문자 보존
- 변경 범위 검증: 노드 단위 diff 결과를 셀·문단 경로로 환산하고 허용 위치 목록과 대조
- 채움 후보 판별: 라벨형 셀과 오른쪽 셀의 내용·테두리 채우기(borderFill) 차이로 값 셀 추정
