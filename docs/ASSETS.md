# 도장·서명·체크 이미지 준비

직인·서명·손글씨 체크를 문서에 넣는 기능(`stamp`)을 쓰려면 **본인 이미지 폴더**가 하나 필요합니다.
양식 채우기·추출·공문 검사 등 다른 기능은 이미지 없이 바로 쓸 수 있습니다.

> 도장·서명 이미지는 스킬 zip 이나 이 저장소에 넣지 마십시오. 스킬을 다시 공유할 때 함께 퍼집니다.
> 본인 명의 문서에만 사용하십시오.

## 1. 준비물

| 역할 | 파일 이름(자동) | 준비 방법 | 권장 개수 |
| --- | --- | --- | --- |
| 도장 `seal` | 도장1.png | 흰 종이에 도장을 또렷하게 찍어 촬영·스캔 | 1~3 |
| 서명 `signature` | 서명1.png … | 흰 종이에 검은 펜으로 서명을 띄엄띄엄 3개 | 2~3 |
| 성명 자필 `name` | 성명1.png … | 같은 방법으로 이름 2~4개 (필요할 때만) | 2~4 |
| 손글씨 체크 `check` | 체크1.png … | 같은 방법으로 √ 3개 | 3 |

서명·체크를 여러 개 두면 문서 안에서 차례로 돌려 쓰고 위치·각도를 조금씩 바꿔 넣어, 같은 그림이 반복돼 보이지 않습니다.

## 2. 촬영 요령

- 흰 종이(A4) 한 장에 **한 종류만** 씁니다. 서명 종이, 체크 종이를 따로 찍습니다.
- 글씨 사이를 손가락 두 마디 이상 띄웁니다. 붙어 있으면 한 개로 인식됩니다.
- 그림자가 지지 않게 밝은 곳에서 위에서 수직으로 찍습니다. 종이 테두리 밖(책상)은 잘라 내거나 종이가 화면을 채우게 찍습니다.
- 도장은 인주를 충분히 묻혀 번지지 않게 찍습니다. 스캔하면 가장 깨끗합니다.

## 3. 자동 정리 (권장)

사진을 Claude 대화에 첨부하거나 PC 연결 폴더에 두고 이렇게 요청합니다.

> "이 사진의 서명 3개를 서명 이미지로 정리해서 `문서\도장` 폴더에 저장해 줘"

Claude 는 다음 명령을 실행합니다(직접 실행해도 됩니다).

```bash
python -m pehwpx assets make 서명사진.jpg --role signature -o 도장폴더
python -m pehwpx assets make 체크사진.jpg --role check     -o 도장폴더
python -m pehwpx assets make 도장스캔.png --role seal      -o 도장폴더
python -m pehwpx assets check 도장폴더
```

| 처리 | 내용 |
| --- | --- |
| 배경 투명 | 종이색(테두리 색)을 기준으로 배경을 투명하게 합니다 |
| 나누기 | 한 장에 여러 개를 쓴 경우 떨어진 덩어리마다 한 파일로 나눕니다(위→아래, 왼쪽→오른쪽 순). 도장은 나누지 않습니다 |
| 여백 자르기 | 글씨·인영에 딱 맞게 자릅니다. 그래서 `width_mm` 이 곧 실제 폭입니다 |
| assets.json | 없으면 만들고, 있으면 해당 역할에 파일을 추가합니다 |

잡티가 따로 잘려 나오면 그 파일만 지우고 `assets.json` 의 `files` 에서도 빼 주십시오. `--max 3` 으로 앞의 3개만 받을 수도 있습니다.

## 4. assets.json (역할 정의)

`examples/assets.json` 을 복사해 이미지 폴더에 두고 파일 이름만 맞춰도 됩니다.

```json
{
  "seal":      {"files": ["도장1.png"], "width_mm": 15, "rotate_deg": 4, "jitter_mm": 0.5},
  "signature": {"files": ["서명1.png", "서명2.png", "서명3.png"], "width_mm": 24, "rotate_deg": 3, "jitter_mm": 0.8},
  "check":     {"files": ["체크1.png", "체크2.png", "체크3.png"], "width_mm": 6, "rotate_deg": 10, "jitter_mm": 1.2, "scale_pct": 10}
}
```

| 키 | 의미 |
| --- | --- |
| `files` | 돌려 쓸 이미지 목록 |
| `width_mm` | 문서에 넣을 폭(mm). 도장은 지름. 예: 개인 도장 17mm |
| `rotate_deg` | 넣을 때마다 ± 이 범위에서 무작위 회전 |
| `jitter_mm` | ± 이 범위에서 위치를 무작위로 이동 |
| `scale_pct` | ± 이 % 범위에서 크기를 무작위로 변화 |

작은 상자(약 3.5mm □)에 체크할 때는 배치 파일에서 그 항목만 흔들림을 줄입니다:
`{"image": "@check", "near": "동의 □", "on": "□", "jitter_mm": 0.2, "rotate_max_deg": 5, "dx_mm": 0.4}`

## 5. 폴더 두는 곳

| 사용 환경 | 방법 |
| --- | --- |
| Claude 데스크톱 앱으로 PC 연결 | PC 에 폴더(예: `문서\도장`)를 만들어 연결 폴더로 지정. "도장 폴더 이미지로 날인해 줘"라고 요청 |
| 웹·모바일만 사용 | 날인할 때마다 이미지 파일과 assets.json 을 대화에 첨부 |

## 6. 사용 예

```json
{"stamps": [
  {"image": "@check", "near": "□ 동의함", "on": "□"},
  {"image": "@seal", "near": "(인)"},
  {"image": "@signature", "near": "(서명)"}
]}
```

```bash
python -m pehwpx stamp 신청서.hwpx 배치.json --assets 도장폴더 --pdf 신청서.pdf -o 신청서_날인.hwpx
```

PC 에 한글이 있으면 `--pdf`(한글로 변환한 PDF)를 주어 실제 좌표로 배치합니다. 결과는 반드시 한글이나 PDF 로 열어 위치를 확인하십시오.
